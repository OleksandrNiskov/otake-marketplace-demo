# Otake Marketplace — Interactive Demo

Clickable static preview of the Otake Marketplace. No backend, account, payment, or installation required.

## Live preview

https://OleksandrNiskov.github.io/otake-marketplace-demo/

**To turn on the public link:** open **Settings → Pages → Build and deployment**, set **Source: Deploy from a branch**, then select **main** and **/(root)**, and click **Save**. GitHub will publish the site's root `index.html`.

## What you can try

- Browse and filter the specialist catalog.
- Open specialist profiles and explore available services.
- Interact with the illustrative map and demo availability.
- Walk through a sample service request.
- View, accept, decline, cancel, and complete sample requests.
- Send demo chat messages, edit demo specialist details, and publish a demo profile.

This is a **design-only, fictional prototype**. Messages and bookings are not sent; any simulated activity stays in your own browser's local storage. Nothing is connected to a production Otake service.

## Project structure

The complete demo is self-contained in `index.html` (styles, JavaScript, and optimized preview images included). There is no build process.
